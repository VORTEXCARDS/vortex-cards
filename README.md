# VORTEX CARDS — PWA starter

Устанавливаемое веб-приложение для Android (PWA), интерфейс на русском языке.

## Важно
Текущая сборка — мобильный PWA-интерфейс и демонстрационный режим. Без подключения Supabase регистрация, переводы, реальная торговля, выкуп и админские операции не выполняются. Объявления на экране демонстрационные. Нельзя принимать оплату или обещать фактическую выплату на основании этой демо-версии.

Утверждённые параметры бизнес-модели:
- стартовая карточка новому аккаунту;
- пригласивший получает +1 карточку за подтверждённого реферала;
- P2P-комиссия 5%;
- заявленная целевая цена выкупа 20 грн — требует реально профинансированного резерва и юридически проверенных условий.

## Запуск локально
1. Установите Node.js 20 или новее.
2. Распакуйте архив.
3. Выполните `npm install`.
4. Скопируйте `.env.example` в `.env.local`.
5. Выполните `npm run dev`.

## Подключение Supabase
Создайте проект Supabase и заполните `.env.local`:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

Затем реализуйте и протестируйте серверные RPC/Edge Functions и политики RLS. Публичный anon key можно использовать во фронтенде только вместе с корректными RLS. Никогда не помещайте service_role key в клиентский код.

## Установка на Android
1. Разместите production build (`npm run build`, папка `dist`) на хостинге с HTTPS.
2. Откройте адрес сайта в Chrome на Android.
3. Нажмите меню Chrome → «Установить приложение» или «Добавить на главный экран».
4. Запускайте VORTEX CARDS с иконки.

Если Chrome не показывает установку, проверьте HTTPS, manifest и service worker.

## Следующие обязательные этапы до реального запуска
- Серверная регистрация/реферальная атрибуция с защитой от саморефералов и повторного начисления.
- Транзакционная БД-логика балансов, блокировок и переводов.
- Резервирование карточек в момент публикации и атомарное завершение сделки.
- Подтверждение оплаты обеими сторонами, споры, модерация и аудит.
- Серверное удержание комиссии 5% (не полагаться на добровольный перевод комиссии).
- Админские роли только на сервере.
- Реальная платёжная схема и юридическая проверка P2P и гарантированного выкупа в Украине.
